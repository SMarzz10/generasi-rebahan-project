# Sumber Data Generasi Rebahan

Folder ini berisi ringkasan referensi yang digunakan untuk konten fakta, statistik,
dan jawaban **Rebahan Bot**. Ringkasan ini bukan pengganti artikel atau jurnal asli.
Gunakan dokumen sumber asli untuk pemeriksaan metodologi dan konteks lengkap.

## Daftar referensi

1. `ringkasan-referensi.md` — ringkasan temuan, konteks sampel, dan cara data
   digunakan di website.
2. `README.md` — penjelasan penggunaan folder sumber.

## Catatan lisensi dan atribusi

- Referensi jurnal dan artikel tetap menjadi hak cipta pemilik masing-masing.
- Website hanya menggunakan ringkasan fakta dan atribusi sumber, bukan menyalin
  keseluruhan isi publikasi.
- Sebelum pengumpulan, lengkapi URL, tanggal akses, dan lisensi untuk artikel web
  yang digunakan jika informasi tersebut tersedia.
- Data survei atau uji coba pengguna untuk proposal harus berasal dari responden
  nyata, bukan dari AI.
